# Avisos de terceiros

FamilyBridge é um projeto de Yruam Käffer de Faria. O pacote inclui AppBundles pré-compilados e código que interage com APIs de SketchUp e Autodesk; os produtos e serviços de terceiros não acompanham este projeto. A execução usa a conta e a franquia APS do usuário.

O fluxo busca um template `Generic Model.rft` de um snapshot público do Revit SDK por HTTPS durante o WorkItem. Confira termos de uso, disponibilidade e compatibilidade do recurso antes de redistribuir ou implantar comercialmente. O código referencia `DesignAutomationBridge.dll` na compilação do worker Revit; não a copie de uma instalação não autorizada.

Este pacote não contém uma licença pública para o código FamilyBridge. A ausência de licença não concede permissão de reutilização, modificação ou redistribuição além do permitido por lei. O mantenedor pode adicionar uma licença em uma futura publicação.
